# HD 開發路線

## 第一階段：音質與原生播放基線

- 固定音源、位置與音量，記錄人聲、低頻、動態與異音。
- 以同響度的原版／上游 EQ 版做 A/B，比較多種素材。
- 驗證短音檔經原生 URL 播放、停止、恢復原狀。
- 唯讀追查 DSP 載入／係數來源；尚不修改功放增益、限制器、分音或驅動。

驗收：音檔播放與恢復成功；改善能重現；沒有增加破音或資源異常。

## 第二階段：NAS 音樂與播報

- NAS 保存內容與日誌，HD 只放小型控制程式。
- 驗證播報前後音量與播放恢復。
- 設置逾時、重試上限、停用方式；確認 data 空間及記憶體。

驗收：斷線不阻塞原廠使用；停止新增服務即可回到原狀。

## 第三階段：HD Client 適配

- 先釐清上游模組與第三方授權，再固定 commit 匯入必要原始碼。
- 依序測服務端連線／版本、事件、播放、收音；最後才配置自動啟動。
- 查清 SoundAI 事件與音訊格式，保留原廠前端可恢復性。

驗收：HD 專用測試紀錄完整，不把 LX06 成功結果當作 HD 驗收。

## 持續條件

- 保留私人基線與每次變更紀錄。
- 不把未知 Bootloader 恢復能力描述為已驗證。
- 每項成果標示「靜態存在／實機觀察／功能驗證／尚未測試」。
